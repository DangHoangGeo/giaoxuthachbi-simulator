# Registers by usage category

Each editable workbook has the same four sheets: **Read me, Equipment, Electrical Lines, Route Points**. Equipment and route IDs are owned once; board source IDs can be referenced across files.

| Category | Workbook | Scope |
| --- | --- | --- |
| [Lighting](lighting/README.md) | [Excel register](lighting/register.xlsx) | Reading, sanctuary, circulation, paths, facade and festival exterior lighting. |
| [Sound](sound/README.md) | [Excel register](sound/register.xlsx) | Loudspeakers, microphones, indoor speech and outdoor overflow. |
| [Fans and ventilation](air-system/README.md) | [Excel register](air-system/register.xlsx) | Ceiling, wall, entrance and exhaust fans for air movement and ventilation. |
| [Exit signs](exit-signs/README.md) | [Excel register](exit-signs/register.xlsx) | E1 maintained exit-sign group. Emergency supply and duration require separate design. |
| [Decoration and furnishings](decoration/README.md) | [Excel register](decoration/register.xlsx) | Seasonal decorative lighting and non-electrical simulator furnishings. |
| [Distribution and controls](distribution-controls/README.md) | [Excel register](distribution-controls/register.xlsx) | DB1, DB2, LC1, FC1 and AV1 enclosures, their shared supply feeders, and the socket-outlet circuits P1–P4. |

[Summary report](../summary-report.md) contains total quantities, service usage estimates, route-length bases and data/engineering completeness. [Register workflow](../register.md) explains refresh, retained inputs and position changes.
