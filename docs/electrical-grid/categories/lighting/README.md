## Editing and coordination

Edit the amber engineering fields here. Preserve stable IDs and follow the [refresh and position workflow](../../register.md). Each equipment/route belongs to one category; shared board sources are referenced by ID in the distribution-controls file. Retired records remain traceable.

## Lengths and usage

Route lengths use 3D centreline geometry; full audio/microphone home runs include upstream distance. Do not add shared bundle lengths again. Usage estimates and missing engineering inputs are reported in the [summary](../../summary-report.md). Pending specifications require design review.
