# Private full-detail model package: retired

**Retired 10 October 2026 by owner decision.** The password-protected full-detail preview and its packaging and publishing scripts were removed; see [access control](access-control.md).

The package was a gzip copy of the full-resolution GLB exported on 8 October 2026 from source revision `c151c71`. It showed the building shell without lights, fans, loudspeakers, statues or the changes made on 9 October, so it was less complete than the viewer that the public [3D visit](viewer.md) now serves.

The record of that package, with its hashes, is kept as history in `exports/private-review/manifest.json` and `exports/sharing/`. The model files themselves were never committed. The earlier version of this document is in Git history at `23e48f1`.
