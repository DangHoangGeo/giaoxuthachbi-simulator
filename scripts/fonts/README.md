# Local fonts for Vietnamese PDF exports

Unmodified Noto Sans Regular and Bold, copied from Codex bundled runtime
26.909.12148, LibreOffice font resources on 9 October 2026. Font metadata
identifies Copyright 2022 The Noto Project Authors and SIL Open Font License
1.1; the copyright and full license are retained in [OFL.txt](OFL.txt).

These files support Vietnamese accents and are subset-embedded by ReportLab.
The exporter checks every printed Unicode character against the local font
mapping before publication. Keep font files and license with the reusable
Python scripts; no network or installed system fonts are needed.

Source project: https://github.com/notofonts/latin-greek-cyrillic
