# Local drawing review

**In development / Đang phát triển. Not for construction / Không dùng để thi công.**

From the project root run `tools/dwg-workspace/start.sh`, then open <http://127.0.0.1:8765>. The first run creates an ignored Python environment under `exports/` and installs `scripts/requirements-dwg.txt`. DWG opening also requires LibreDWG (`brew install libredwg` on macOS); DXF does not. Set `DWG_WORKSPACE_PORT` before starting to change the port. Stop the server with Ctrl-C. Use a desktop browser. Files are limited to 64 MB and 300,000 model-space entities; DWG conversion has a 180-second time limit and a 512 MB output limit.

Choose a local DWG or DXF, or use “Open local project DWG” when the fixed local source is present. Drag or use the arrow buttons to pan; scroll or use + / − to zoom. Center returns to the middle at the current zoom, while Fit view resets the viewport. Click a visible object, and Shift-click to add or remove objects; export either the current sheet or the selected objects to a vector PDF. The matching 23 October 2026 church DWG is recognized by SHA-256 and offers its 27 recorded drawing frames plus 23 enlarged tower crops (T01–T23: front ornament, side faces and the unlabelled tower cut ET) from `docs/layout_design/dwg-2026-10-23/tower-details-23102026.json`, the same boxes as PDF volume 11. Other files open in model space. The church file is large: initial conversion and indexing can take a minute or more and exceed 1 GB of memory. Source files are never edited. Processing and temporary conversions stay on the computer; stop the server to remove its temporary session. The output PDF is downloaded by the browser to its configured download folder. Drawing sources and derivatives remain under publication hold H1; do not publish them without permission.

The conversion uses LibreDWG and ezdxf's model-space XY rendering. DIMENSION cached graphics are retained where supported; this is not a native AutoCAD plot. ACIS, external references, images and other unsupported objects may be omitted; text, fonts, hatches and line styles may differ. Converter warnings require investigation and a native CAD comparison. The PDF is fitted to A4 landscape, not a calibrated plot. Export clips to the selected sheet frame. Selection is by top-level entity handle; a block or dimension is one object. Empty/unrenderable entities cannot be selected. Entire-model view can be slow for large drawings.

No unit conversion is performed. For this church drawing, `INSUNITS=1` indicates inches for insertion while dimension chains suggest millimetres; ISSUE-R06 remains open for the designer. The drawings and outputs are design-development references, not survey or construction approval.

Run the synthetic API and vector-export checks with `exports/dwg-workspace-venv/bin/python tools/dwg-workspace/test_workspace.py`. They do not include private drawings.
